# Cómo contribuir

Enrailar es un proyecto open source. Los cambios entran por pull request. `main` no acepta pushes directos ni force push.

## Antes de abrir un PR

1. Leé el [código de conducta](CODE_OF_CONDUCT.md).
2. Buscá si ya hay un issue. Si el cambio es grande, abrí uno antes de escribir código.
3. Un PR, un tema. Un diff chico se revisa mejor.
4. No mezcles refactors con comportamiento nuevo.

## Privacidad

El repositorio es público. No commitees datos de personas: nombres, correos personales, montos o acuerdos. Las casillas de rol del proyecto (`hola@`, `hackatrain@` y `prensa@enrailar.com`) sí pueden aparecer.

No commitees secretos ni valores de variables de entorno. Si un nombre de variable es público, el valor queda vacío en ejemplos y documentación.

## Flujo

1. Creá una rama desde `main` actualizado.
2. Hacé commits con mensajes que expliquen el porqué.
3. Abrí el PR con la plantilla. Contá cómo probarlo.
4. Esperá a que el CI quede verde.

## Reportar problemas

- Bugs y propuestas: [issues](https://github.com/sinequix/enrailar/issues/new/choose).
- Vulnerabilidades: [SECURITY.md](SECURITY.md). No abras un issue público.
